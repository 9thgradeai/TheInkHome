# 90-Day Growth Plan

## Days 1-14 — Technical foundation
- Sitemap, robots, canonical, metadata, noindex on 404, breadcrumbs, WebSite schema.
- Automated SEO tests in CI.
- llms.txt.

## Days 15-30 — Editorial architecture
- Homepage, About, submission guidelines, editorial policy, authors, stories, internal linking, metadata quality.

## Days 31-60 — Authority & original resources
- Research keyword opportunities (qualitative).
- Publish 1-2 high-quality writer resources.
- Editorial collections.
- Author recognition.
- Distribution.

## Days 61-90 — Data-driven optimization
- Analyze search queries (when data available).
- Improve high-impression pages.
- Optimize weak CTR.
- Update outdated content.
- Consolidate competing pages.
- Evaluate organic conversions.

Non-guaranteed. Measures: indexed pages, impressions, clicks, CTR, queries, top landing pages, submission visits.
